# 문서 표현 검사

1. 요청받은 문서 파일만 선택한다.
2. 이 스킬의 `scripts/check_prose.py`를 절대경로로 실행한다: `python3 /스킬경로/scripts/check_prose.py 문서.md`.
3. 경고 주변 문맥을 읽고 실제 모호함인지 판단한다. 경고만으로 오류라고 단정하지 않는다.
4. 허용된 범위에서 수정하고 변경 파일만 다시 검사한다. 식별자·조건·기술 사실은 유지한다.
5. 검사 범위와 남은 경고를 보고한다. 경고 0개는 사실 검증이나 앱 테스트 통과가 아니다.

Vale가 필요하다. 미설치면 누락을 보고하고, 별도 허용 없이 설치기를 내려받아 실행하지 않는다. 이 도구는 로컬 검사만 수행한다. 임의의 전체 소스·비밀 설정을 입력으로 넘기지 않는다. PUML은 별도 렌더러로 확인한다.
